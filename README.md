# MicroTick

> The software platform powering Wamacani WiFi.

MicroTick is a software-defined hotspot billing platform built around
RouterOS automation, mobile payments, and session-wallet technology.

## Project Status

🚧 Under active development.

## Vision

Build an affordable, scalable, payment-first hotspot platform that enables
individuals and businesses to resell internet access with minimal operational
complexity.

## Engineering Principles

MicroTick is developed using the following principles:

- Test-Driven Development (TDD)
- Small, reviewable changes
- Architecture before implementation
- No unnecessary dependencies
- No speculative abstractions
- Production-quality code from the first commit
