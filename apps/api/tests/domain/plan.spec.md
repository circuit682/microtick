# Plan Specification

## Purpose

A Plan represents a purchasable internet access offering.

## Requirements

- Every plan has a unique identifier.
- Every plan has a display name.
- Every plan has a price in Kenyan Shillings.
- Every plan has a duration.
- Every plan can be active or inactive.

## Constraints

- Price must be greater than zero.
- Duration must be greater than zero.
- Name cannot be empty.
